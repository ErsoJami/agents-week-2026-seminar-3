# Семинар 3: AI Agent Workflow

Практический ноутбук по созданию AI-агентов: цикл TAO, мультиагентная система поддержки авиакомпании, контроль качества с критиком и оценка результатов на τ-bench.

Откройте ноутбук в Jupyter и выполняйте ячейки по порядку. Для доступа к моделям настройте необходимые API-ключи в своей среде.
